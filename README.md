# mmab
Make Me A Billionaire

A one-page, multilingual "pay to the order of" site: send any amount, help reach nine zeros.

**Live:** https://mmab.sugrobov44.workers.dev

The whole site is `public/index.html` (no build step). Pushes to `develop` deploy automatically via Cloudflare.
Language can be forced with a hash, e.g. `#ru`, `#en`, `#ar`.
